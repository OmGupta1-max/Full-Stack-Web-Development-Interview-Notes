# 36‑Week Study Plan (2 hours/week)

Notes
- Each "week" = one 2‑hour session. If you can do micro-sessions (15–30m) daily, you'll progress faster.
- Focused stack: Next.js + TypeScript + tRPC/GraphQL + Prisma + PostgreSQL + Tailwind. Swap framework (SvelteKit) if desired.

Weekly session structure (2 hours)
- 10 min: review last session + plan
- 80–90 min: focused learning/coding
- 20–30 min: summary/notes + one LeetCode practice or flashcard review

Phase A — Foundations & JavaScript (Weeks 1–8)
Weeks 1–2: Web fundamentals
- HTML semantics, responsive CSS (Flexbox/Grid), accessibility basics.
- Deliverable: simple portfolio page.

Weeks 3–5: Modern JavaScript + TypeScript basics
- ES6+, async/await, module system, basic TS types.
- Deliverable: convert small JS utilities to TS.

Weeks 6–8: DOM, Fetch, Browser APIs
- Build small interactive app (todo/weather) and deploy.

Phase B — Frontend Framework & UI (Weeks 9–16)
Weeks 9–12: Next.js + React fundamentals
- Pages, routing, components, hooks, ISR/SSG/SSR basics.
- Deliverable: frontend CRUD app.

Weeks 13–14: Styling & UI tooling
- Tailwind, responsive components, accessible forms.

Weeks 15–16: Testing & performance basics
- Jest + React Testing Library; Lighthouse checks.

Phase C — Backend & Databases (Weeks 17–24)
Weeks 17–19: Backend APIs with Next.js API routes / tRPC
- Routes, middleware, validation, error handling.

Weeks 20–22: Databases with Prisma + PostgreSQL
- Schema, migrations, basic queries, indexes.

Weeks 23–24: Auth & Security
- JWT or session, bcrypt, input validation, basic OWASP awareness.

Phase D — Deployment, CI/CD, Observability (Weeks 25–28)
Weeks 25–26: Deployments
- Deploy full stack (Vercel for frontend, Railway/Heroku for Postgres/backends), env vars.

Weeks 27–28: CI/CD + Docker basics
- GitHub Actions: run tests & lints; Dockerfile for app.

Phase E — Algorithms & System Design (Weeks 29–36)
Weeks 29–32: Algorithms
- Focus on patterns: sliding window, two pointers, hashes, recursion.
- Goal: 2 problems/week (or 1 + pattern reading).

Weeks 33–36: System design + interview prep
- Practice 3 prompts; prepare architecture notes for each project.

Checkpoints
- Month 1 (W1–4): portfolio + one small app.
- Month 3 (W9–12): frontend CRUD app.
- Month 6 (W25–28): deployed full‑stack app with README.
- Month 9 (W33–36): two polished projects + system‑design notes + regular LeetCode practice.

Deliverables per project
- README with setup & deploy instructions
- Live demo link, screenshots
- API examples and interview talking points

Daily micro-practice ideas (optional)
- 15 min: flashcards or read a short chapter
- 30 min: coding kata or tiny feature
