# Interview Notes — Modern TypeScript Full‑Stack (Study & Interview Repo)

Purpose
- A compact, interview-focused notes repo and study kit for Full‑Stack Web Development using a Modern TypeScript stack (Next.js + TypeScript + tRPC/GraphQL + Prisma + PostgreSQL + Tailwind).
- Optimized for a 2 hours/week schedule leading to interview readiness in ~9 months.

What's included
- STUDY_PLAN.md — 36‑week study plan and checkpoints.
- FLASHCARDS.md — quick Q/A flashcards for review.
- CHEATSHEETS.md — practical code snippets and commands.
- PROJECT_TEMPLATE/README.md — project README template with interview talking points.
- LEETCODE_PLAN.md — algorithm practice plan.
- SYSTEM_DESIGN_NOTES.md — quick system design checklist.
- .github/workflows/ci.yml — starter CI workflow (Node: lint/test).

How to use
1. Pick one focused daily micro-task if possible (15–30 min) and follow the weekly 2‑hr structure in STUDY_PLAN.md.
2. Build two projects (frontend-focused + full-stack) using the PROJECT_TEMPLATE.
3. Practice algorithms and system design using LEETCODE_PLAN.md and SYSTEM_DESIGN_NOTES.md.
4. Use FLASHCARDS.md for weekly review before interviews.
