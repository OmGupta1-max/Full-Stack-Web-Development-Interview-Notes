# LeetCode / Algorithms Plan (2 hrs/week)

Goal
- Quality over quantity. Learn patterns and apply.

Weekly expectation
- 1–2 problems per week: aim for one problem (medium) + review pattern notes.
- Alternate: 1 problem + 30 min reading of pattern solutions.

Priority patterns (in order)
- Arrays & Hashing
- Two Pointers / Sliding Window
- Fast & Slow pointers
- Stacks & Queues
- Trees (BFS/DFS)
- Binary search
- Dynamic programming (basic)

Plan example (4 weeks)
- Week 1: Arrays (two-pointer problem)
- Week 2: Hashmap (counting problem)
- Week 3: Sliding window (substring problem)
- Week 4: Tree (binary tree traversal)

Notes
- Practice explaining solution out loud and writing clean code under 45 minutes.
