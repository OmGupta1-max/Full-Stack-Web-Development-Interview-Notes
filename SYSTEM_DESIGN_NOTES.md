# System Design — Quick Checklist & Practice Prompts

Core components to cover in a 15–30 min answer
- Goals & constraints (throughput, latency, consistency)
- API surface & data model
- High-level components: load balancer, app servers, DB, cache, CDN, messaging
- Data partitioning & indexing strategy
- Caching strategy (what to cache and where)
- Consistency & replication choice
- Scaling plan: read replicas, sharding, autoscaling
- Monitoring & SLOs, failure handling, backups
- Security considerations: auth, rate limiting, encryption

Practice prompts
- Design an Instagram feed
- Design a URL shortener
- Design a realtime chat app
- Design a job queue system
